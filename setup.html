ShadowWatch — evidence setup

Checkpoint lives in GitHub. No database. Each step says exactly what it did.

1 · Check

Is the token configured, and is the checkpoint seeded? Reads only.

2 · Seed the checkpoint

Reads the last sealed 255/255 report and writes its anchor as the starting checkpoint. Happens once — re-running is refused, not repeated.

3 · Run

Walks each wallet from its checkpoint to one pinned ledger, reads balances, and commits only if every wallet proves with no contradictions.
